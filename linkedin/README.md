## Ten-minute finish checklist

1. Edit page → Header: upload logo and cover, paste tagline.
2. Edit page → About: paste overview, website, phone, industry, size, type, founded, specialties.
3. Edit page → Locations: add the Cottage Hills address as primary.
4. Edit page → Buttons: set the custom button.
5. Manage → Community hashtags: add the three hashtags.
6. Amanda adds Fenix 5ive as her current position on her own profile so she shows up as an employee.
7. Publish the launch post, then pin it.
8. Later: Settings → Verification to apply for the verified Page badge, and add a Lead Gen form if wanted.
